# 协纪择日 · 你的私人黄历

输入生日和想做的事（约会、面试、签约、搬家……或祭祀、栽种等传统用事），看看接下来哪几天最适合。

- 宜忌、建除十二值星、黄道黑道、神煞：依《钦定协纪辨方书》一系的推算体系
- 现代活动对应到书中的传统用事（面试→赴任，签约→立券，约会→会亲友……）
- 结合生日：生肖冲合、本命日、十神参考
- 纯前端，本地运算，不上传任何数据；可生成 9:16 分享卡

> 择日是天气预报，不是人生判决书。民俗文化娱乐，不构成任何建议。
